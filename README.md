# report-automation

Automação em Python para **extração de relatórios** em sistemas web e **organização de arquivos exportados** nas pastas.  
A rotina foi desenvolvida para rodar diariamente de forma agendada eliminando esforço manual.

---

## 🚀 Funcionalidades
- Acessa 2 sistemas distintos via Selenium e realiza a extração de **3 relatórios**.
- Realiza o **download automático** dos relatórios.
- Faz a **movimentação e renomeação** dos arquivos exportados para suas pastas corretas.
- Utiliza **variáveis de ambiente** para credenciais e URLs (sem segredos hardcoded).
